 MBTI Roast Generator

A fun (and mildly offensive) MBTI-based roast generator.
Built purely for entertainment. No personality types were harmed… emotionally maybe, but we move.

 Overview

This project generates sarcastic roasts based on MBTI personality types.
Each type gets its own set of custom insults because apparently stereotyping 16 categories is peak productivity.

 Features

Roasts for all 16 MBTI types

 Randomized output every time

 Organized structure (because chaos has limits)

 Fast and lightweight
